# 🎯 SANTANA RH SOLUÇÕES

Sistema completo de **gestão de vagas e candidaturas** para a SANTANA RH SOLUÇÕES, uma empresa de recrutamento rápido e eficiente.

---

## 📋 Sobre o Projeto

O projeto foi desenvolvido para automatizar o processo de **divulgação de vagas** e **recepção de currículos** de candidatos, com um painel administrativo para a recrutadora gerenciar as oportunidades.

### Funcionalidades:

| Módulo | Descrição |
|--------|-----------|
| **Painel Administrativo** | Cadastro, edição e remoção de vagas; dashboard com estatísticas. |
| **Site Público** | Exibição de vagas para candidatos, com formulário integrado ao WhatsApp. |
| **Candidatura Simplificada** | O candidato preenche os dados (nome, contato, experiência) e envia diretamente pelo WhatsApp, anexando o currículo. |
| **WhatsApp Integrado** | Todos os dados vão para o número da empresa, sem necessidade de e-mail ou serviços externos. |

---

## 🚀 Tecnologias Utilizadas

| Ferramenta | Função |
|------------|--------|
| **HTML5 / CSS3** | Estrutura e estilo das páginas públicas |
| **JavaScript** | Interatividade (envio via WhatsApp, validações) |

## 🧪 Como Testar

1. **Acesse o site público** e veja as vagas disponíveis.
2. **Clique em "Candidatar-se"** em uma vaga.
3. **Preencha o formulário** e clique em "Enviar pelo WhatsApp".
4. O WhatsApp abrirá com a mensagem pré-preenchida – anexe o currículo e envie.
5. **Acesse o painel admin** com a senha `admin123` para cadastrar novas vagas.
